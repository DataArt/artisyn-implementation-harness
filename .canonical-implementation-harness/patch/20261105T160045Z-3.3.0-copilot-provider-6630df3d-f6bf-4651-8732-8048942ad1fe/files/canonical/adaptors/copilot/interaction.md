# Questions and approvals in Copilot

Use `ask_user` only when exposed and permitted, otherwise ask in conversation.
Respect a no-question setting; it does not authorize guessing required answers. Present
a concrete proposal and preserve existing sign-off gates and prior authorization.
Silence, a tool acknowledgement, a mode transition or a successful script is not
approval. Do not change permissions, trust folders, or enable autopilot for the user.
