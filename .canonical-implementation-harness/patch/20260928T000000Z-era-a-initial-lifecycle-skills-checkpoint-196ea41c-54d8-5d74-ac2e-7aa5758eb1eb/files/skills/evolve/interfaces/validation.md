# Validation interface

Validation.md records candidate identity and content hashes, acceptance criteria,
and a scenario table: input/context, expected behavior, method, actual outcome,
evidence and pass/fail/blocked result. Cover intended use, non-trigger behavior and
at-risk existing behavior as applicable. Explain any not-applicable category.

Include structural checks for frontmatter, deployment layout, companion references,
caller wiring and instruction conflicts. Record tool/runtime limitations and what
was actually executed. Finish with verdict, remaining failures and next action.
A blocked required scenario cannot be reported as a pass.
