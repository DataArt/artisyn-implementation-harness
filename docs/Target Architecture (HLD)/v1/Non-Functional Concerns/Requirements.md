# Non-Functional Requirements

## Scope

These requirements govern the platform's Web, Auth, Infrastructure and Discuss containers (see `Containers/`), the CI/CD pipeline that builds and deploys them, and every actor reaching the site over HTTPS — internal engagement team members (~10 users) and, for the Discuss container, GitHub accounts with or without repository permission. They apply uniformly across environments provisioned by this repo's CDK stacks; no environment is exempt.

## Flows

No critical ordered process (recovery, access-control sequence, deployment sequence) is required to interpret these requirements beyond what is already documented per-container: the auth challenge/pass-through sequence is in `Containers/Auth.md`, and the CD deploy sequence is in `docs/Engineering Guide/Infrastructure/03 CI-CD Pipeline.md`. This document does not duplicate those sequences.

## Constraints

- No cost ceiling defined for this engagement
- Small team, internal access only (~10 users)
- Fixed-duration engagement scope
