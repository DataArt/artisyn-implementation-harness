# Non-Functional Requirements

## Scope

These requirements govern the platform's Web, Discuss, Implementation Harness E2E, Log Hub and Harness Release Pipeline containers (see `Containers/`), the CI/CD pipeline that builds and deploys them, and every actor reaching the site over HTTPS — any browser, and, for the Discuss container, GitHub accounts with or without repository permission. The site is public; no auth boundary scopes who can reach it. Accessibility requirements (`NFR-A*`) live in `Accessibility.md` in this folder.

## Flows

No critical ordered process (recovery, access-control sequence, deployment sequence) is required to interpret these requirements beyond what is already documented per-container. No deploy sequence is currently documented: the former CDK-based deploy sequence was retired with the Infrastructure container, and the GitHub Pages deploy sequence that replaces it does not exist yet.
