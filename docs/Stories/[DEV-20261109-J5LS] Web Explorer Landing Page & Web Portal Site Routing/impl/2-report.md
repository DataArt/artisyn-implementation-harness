### Step 4 addendum — fix flattened/overlapping heading font

Developer reported `h1`/`h2` rendering with overlapping, collided letterforms. Root cause: `Inter` was named in `font-family` but never actually loaded (no `<link>`/`@font-face` anywhere) — the browser silently substituted a fallback, combined with extremely tight `letter-spacing` (`-.075em` on `h1`, `-.058em` on `h2`) that only a font with matching metrics could carry without glyphs colliding. Fixed both halves: added a proper Google Fonts `<link>` for Inter (weights 400–800) to `index.html`, and relaxed `letter-spacing` to `-.02em` on both `h1` and `h2` (matching what `.slide__title` already used safely), with `font-weight` set to the nearest weight actually loaded (800/700) instead of the arbitrary 750/740. Rebuilt — all checks pass, bundle unchanged (Google Fonts is an external stylesheet, not part of the JS/CSS budget).
