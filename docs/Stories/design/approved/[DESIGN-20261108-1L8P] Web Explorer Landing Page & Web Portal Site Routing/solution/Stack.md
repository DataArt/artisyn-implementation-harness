## Compatibility note

Web Explorer's dependency set (React 19, Tailwind 4, Motion) is new to this monorepo — today's only other app (`apps/web-docs`) depends on VitePress/Vite internals only, with no React in the dependency graph. Joining the root Yarn workspace and single lockfile means `yarn npm audit` (NFR-11's existing CI gate) covers these new dependencies without any config change, since the gate is already root-lockfile-scoped.

## No rollback dependency change

If Web Explorer's version pin (Architecture.md decision 2) fails verification, the fallback is rebuilding the app on root-aligned versions, not reverting any existing dependency.
