# Principles

The beliefs the harness is built on.

_Known:_ from `docs/Harness/package/00 Overview.md` — **"Reduce scaffolding over time."** Every ticket should be faster than the previous one, because the conventions it discovers are encoded into skills and inherited by future tickets. This is delivered through three things:

| Principle                  | What it means                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Repeatability**          | The same lifecycle steps run every ticket — quality doesn't depend on remembering the right prompts          |
| **Convergence**            | Conventions discovered during one ticket are encoded as skills and inherited by future tickets               |
| **Architecture coherence** | Planning audits the target architecture before any code is written; deviations must be justified and tracked |
