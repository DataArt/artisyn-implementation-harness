# Progress in Codex

Use an exposed planning/progress tool when available and permitted; otherwise use
the durable report alone. Tool names and availability vary by host. Do not assume
Claude task tools exist and do not create a persistent goal merely to track steps.
Map the shared work units to supported native statuses and enforce dependency
order yourself if the tool has no dependency graph. Record failures and blocked
dependencies in the report. Updating progress does not enter Plan mode or approve work.
