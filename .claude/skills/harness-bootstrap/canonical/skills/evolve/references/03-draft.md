# Draft — internal Triage procedure

Invoked by Triage, not exposed as {{provider:invoke:evolve}} draft.
Read [the improvement interface](../interfaces/improvement.md) and the scoped report.
Legacy {{provider:skills_root}}/drafts/{name}.md candidates may be imported without deleting
the original; record its source and do not activate it while importing.

Read the affected owner, its callers, the applicable authoring/documentation guidance,
and any provider-specific format already used by this project. Prepare the smallest
change satisfying the acceptance criteria in the candidate directory. New skills
use {name}/SKILL.md with name and description frontmatter; agents use the configured
agent format. Preserve companion paths and load substantial references progressively.
Use scripts for repeatable mechanical work when justified, not for open-ended judgment.

Record destination paths, before-content hashes (or absence), proposed files and
explicit removals in Report.md. Preserve the existing active version until Adopt.
Define representative positive, negative-trigger and regression scenarios using
[the validation interface](../interfaces/validation.md). Show the candidate and
its scope for review. Draft completion requires inspectable content and criteria.
