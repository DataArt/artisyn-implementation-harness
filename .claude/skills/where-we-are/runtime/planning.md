# Planning in Claude

If exposed and permitted, use EnterPlanMode for exploration and proposal drafting,
respect its assigned plan-file and write restrictions, and use ExitPlanMode to
present the proposal for approval. Use the interaction procedure for open decisions.
If these tools are unavailable, perform planning only without implementation;
present the proposal in conversation or an allowed planning artifact and require
the same explicit approval. State that native mode was not activated.

After actual approval and when writes are allowed, persist the identical approved
content at the workflow's project plan path. A mode exit alone is not evidence of
approval. Do not begin implementation until all workflow sign-offs are satisfied.
