# Write and review

Write the files, then show them. Never ask for approval of content that is not on
disk yet: the developer reviews the artifact in their editor, not in chat.

Write the authorised set of local docs/config files, check references and
consistency, then present a combined summary. Keep going through routine items.
Ask only about an unsettled decision or something only a human can verify.

When a phase sign-off (`patterns/phase-sign-off.md`) names this pattern — for
example the persisted `1-plan.md` at the end of Plan — the sign-off is the one
stop. Present the file there, once, and wait.
